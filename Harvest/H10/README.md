Method note: Lean's whitespace/comment code is `partial`, so the Lean side of W-rows is a TOTAL FUEL MIRROR transcribed from the source (`fcb`, `lws`, `nameOfScopes`, `leanEnd`); mirror↔Lean is transcription plus the differential runs below (real `lean` on the F-files), the nano↔mirror part is kernel-checked.
Byte scan = `Char` scan: every trigger (`-` `/` `!` LF) is ASCII, never inside a UTF-8 multi-byte sequence.

## Where it stops
Proved = nano's decision equals the transcribed Lean decision on ALL inputs (fuel ≥ length), and the F1/F2/F3 rows show where nano's current rule differs. Not provable in the kernel: `partial` loops themselves (`whitespace`, `finishCommentBlock`, `takeUntilFn`: mirror faithfulness is the only unproved link), `Parser.info` (not reducible), and anything that reads the environment (`open`, `variable`, `universe`, `set_option` effects, name resolution). Mirror faithfulness is supported by the observed Lean 4.34.1 behaviour of the three F-inputs (the `lean` binary agrees with the mirrors on each).
