Generated by `../run_bench.sh` (riscv.csv, scaling.csv) and `../profile_self.sh` (self_S_regions.txt). Deterministic: rerunning gives the same numbers.
- riscv.csv: `program,input,src_bytes,compile_instr,code_bytes,run_status,run_instr,out_bytes`. `run_status` as in run/README.md (0 ok, 1 empty output, -2 buffer capacity). For `self_S` the compile is the whole row (its "run" is the compiler itself and is not benchmarked).
- scaling.csv: compile cost of synthetic programs (`chain_K`: K defs, each calling the previous; `flat_K`: K independent defs summed by `m`; `expr_K`: one expression with K byte reads).
- self_S_regions.txt: per-function profile of the self-compile (see BENCH.md).
