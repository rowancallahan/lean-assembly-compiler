## Notes

- Most rows fail on the type, not the body: a polymorphic `α` result (`second`, `third`, `thirdOption`), a result type built from `MyList` of types (`myListOfList`), a function result (`ConfigIO α`), or a `Type` result (`ReaderT`, a type and not a function). These are the "polymorphic / type-valued" bucket of `BOOK_SURVEY3.md`.
- `Config` is a structure with a `String` field, and the `frontx_ind` form (`frontx_ind_type Config := Config`) is accepted, but the `ite` in the body is not a constructor match (`preFile`, `preDir`) and `Config.mk` has no equations (`inDirectory`). A `String` result is also unsupported.
- `configFromArgs` fails with `unknown free variable`, which is an internal error, not a typed unsupported case. It is the one row worth a separate report to the compiler owner.
- `doList` is `[Applicative f]`, polymorphic in `α` and `f`, and its only function argument is the action, which is not known at compile time, so `frontx_hof` has no site. The error is the universe-polymorphism check.
- The log has 4 `PANIC at Lean.Expr.appArg!` lines, printed while the `unsupported result type` messages are built. They are not attributed to a single row.
