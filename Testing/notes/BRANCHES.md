## What is trusted, per branch
* **Everywhere:** the Lean kernel of that branch's toolchain; `Spec/` (hash-frozen, `Spec/FROZEN.sha256`, incl.
  `Spec/Alloc.lean`); the source-language definitions listed in `Testing/notes/NANO_V2_REVIEW.md` §2; the generator
  chain (`build_self_S.py`, `gen_cert.py`, `srclink/gen.lean`; their outputs are kernel-checked).
* **`nano-v2-src`:** in addition, the Sail RISC-V model **as published** (its opaque platform / float declarations
  are the only extra axioms, pinned in `review_axioms.txt`).
* **`lean-4.34`:** no machine model is used by the default build. The generic theorems hold for any `JTarget` whose
  `Laws` are proved; no target is instantiated there yet. The ARM target will add the Sail ARMv9 model as published.
* **`rv434-experiment`:** the hand edits to the RISC-V model are trusted there, so its RISC-V theorems are weaker
  evidence than `nano-v2-src`'s.

## Modules of `Nano/V2Self` that need the RISC-V model (not built on `lean-4.34`; kept in the tree, untouched)
Everything that reaches `LeanRV64D` through `Machine/SimW` (which imports `Nano.V2.Enc` / `Nano.V2.Sim` →
`Riscv.Steps.*`):

* `Proof/Machine/SimW`, `SimX`, `RvStep`, `RvTarget`
* `Proof/Main/RvTop`, `RunsTopO`, `SelfLink`, `SelfC`
* `Proof/Tests/AuditWitness`
* `REVIEW.lean`

Also not built on `lean-4.34` (not default targets there): the `Riscv` lib (195 of its 200 modules reach the model),
`Spec.Riscv` / `Spec.RiscvMachine` / `Spec.Implements1`, and the 14 `Compiler.Front.Pipe*` modules that import the
model. The list is generated by import-graph search (any module whose import closure reaches `LeanRV64D`).

## Moving work between the branches
* Proofs go to `nano-v2-src` first (4.29, the RISC-V result), then are merged into `lean-4.34`, where only 4.34
  porting fixes are added (`lean-4.34` commits are titled "(Lean 4.34.1)").
* Build serialized on 4.34.1 (one lake build at a time). This box's memory limit is about 15 GB, and two
  concurrent 4.34 builds were OOM-killed.
