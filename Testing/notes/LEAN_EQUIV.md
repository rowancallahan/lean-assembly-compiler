## Result
T and done: rows 1, 2, 4, 5, 12, 14, 15 (13 theorems, axioms `propext`, `Quot.sound` only; `Nano/LeanEquiv/REVIEW.lean`).
Finding restated as a theorem: row 2: nano's identifier-first set = Lean's ∪ {`'`}. Removing 39 there makes it an equality.
Everything about *sequencing* (token loop, comments, Pratt loop, layout) is `partial` in Lean: no kernel theorem is possible against Lean's code; only against a hand-written total mirror, whose faithfulness is again a fuzz claim.

## Proposed spec mirroring (needs SYNTAX-EXP; not done)
* `LexSpec.isW := fun b => Lean.isIdRestAscii b && b != 33 && b != 63` and `isD := fun b => (Char.ofNat b.toNat).isDigit` would make rows 1, 4 definitional. Cost: every `decide` over `isW` in Lex2Sound re-checks; no gain in trust over the theorems here. Recommendation: keep nano's definitions, keep the theorems.
* Row 2: reject a word starting with byte 39 in `step` (changes the trusted spec and the lexer `s10`; selfhost_gate needed).
