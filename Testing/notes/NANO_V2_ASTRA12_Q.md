# Question for Astra (round 12): write the rest of C's parser in S

Please write actual code, not just a plan.

## Context
C is a self-hosted compiler written in a tiny Lean subset S. Its parser (below, `Par0.lean`) is an explicit task machine over ONE heap buffer `h`. It already handles: `def f (a b : UInt64) : UInt64 := EXPR` with literals, params, parens, `|||` `&&&` `+ -` `*` `<<<` `>>>`, `if A == B / A < B then T else E`, `let x := V; BODY`. It emits a flat pre-order AST (format below).

## Rules S code must obey (the front end rejects anything else)
- Types: UInt64, Nat (fuel only), Buf (= List UInt64), List UInt8 (input), pairs `T × T`.
- Prelude only: bnew, bsize, bget, bset, bpush, rd, len, len', put.
- Names: ONE letter + digits (`y9`, `d3`, `q1`); `tt`, `ok`, `np` are rejected.
- Conditions only `a == b` or `a < b` (no &&, ||, ≤, ≠, >, no parenthesised `if` in a condition, no `==` between two bare numerals — use typed consts k0/k1).
- Loops: `def f : Nat → … | 0, … => Z | n + 1, … => …` with self-calls `f n …` only in tail position. No other recursion. Callees defined before callers.
- A Buf passed into a loop/call is MOVED (dead afterwards); so ALL parser state lives in one heap `h` threaded through; every read `bget h …` must be let-bound BEFORE `h` is consumed.
- Too many `let`s in one def is rejected (frame/slot limit) — split into helper defs.
- Region bases come from the layout constants d1..d11 (prefix sums).

## Output AST (IR v2.1, FINAL tags)
`IRV=2`, then per def: `DEF(20) id npw nslots kind nres`, body, `ENDDEF(21)`. Nodes (pre-order, fixed arity):
CONST 1 v | LOCAL 2 slot w | BIN 3 op a b (add1 sub2 mul3 and4 or5 shl6 shr7) | IF 4 cmp a b t e (eq1 lt2) |
LET 5 slot w v body | PAIR 6 n c1..cn | CALL 8 id n a1..an | PRIM 9 p args (ISIZE1 RD2 LEN3 PUT4 BNEW5 BSIZE6 BGET7 BSET8 BPUSH9) |
LOOP 10 zero step (fuel = param slot 0, state params after) | CONTINUE 11 e (width npw-1).
A pair variable = w consecutive slots; `let (a, b) := v` = `LET slot w v body` with a at slot, b at slot+width(a).
Calls pass fuel as ordinary first arg (`len' x` = PRIM ISIZE; numerals = CONST).

## What to write (in S, same style as y9)
1. **Pairs:** typed params `(x : UInt64 × UInt64)`, tuple literals `(a, b)`, `let (a, b) := v; body`, `.1` / `.2` if cheap. Track width per name.
2. **Prims + calls + multiple defs + main:** a def table (name → id, npw, nres, source arity), call parsing with argument atoms, width check (reject if total arg width ≠ callee npw), the 9 prims, multiple defs in order, last def `def m (x : List UInt8) : List UInt8`.
3. **Fuel loops:** the equation form above, with the PROVISIONAL bit per operand (your round-10 design: confirm at FINISH, reject `f n s + 1` and `(if … then f n s else s) + 1`), CONTINUE width check = npw-1.

For each: new task codes + their exact heap effects, then the S code (new helper defs + new branches of y9), keeping existing behaviour. Mark anything you are unsure would pass the rules above. Also: 3–5 test programs per part (valid + must-reject).
