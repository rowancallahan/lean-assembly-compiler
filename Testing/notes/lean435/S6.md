# SURVEY-S6: compiler C sources + Lex / Parser proofs on Lean 4.36.0

Toolchain: `lean-4.36.0-linux` from the GitHub release asset. Source: `nano-v2-src` at `ab0e3c5f`.
Scratch worktree only; nothing but this file is committed. Scratch lakefile: one `Nano` lib, no
`Lean_RV64D` require, same `moreLeanArgs` (`--tstack=400000 --threads=2`). 4 cores, 15 GB.

Scope: `Nano/V2Self/C` (5), `Nano/V2Self/Proof/Lex` (4), `Nano/V2Self/Proof/Parser` (88) = 97 modules, 25.5k lines.

## Headline

- **Skipped (need Sail): 2** — `Proof.Parser.DBPar`, `Proof.Parser.MainTyP` (reach `LeanRV64D` via
  `Proof.Gen.DBNode` / `Proof.Bridge.MainTy`). Decided by transitive import closure.
- **Built: 95.** On plain 4.36.0, **71 OK, 24 error**. All of `C/` and `Lex/` are OK; every error is in `Parser/`.
- With the scratch fixes below all 95 build: clean build **110 s wall, 342 s CPU, peak 1.86 GB** (single process).
  No `sorry` introduced.
- One root cause for nearly all of it: **4.36 `isDefEq` respects transparency**, so `simp`/`simpa`/`rw`/`split`
  no longer close or match things that were only equal at default transparency.
  `set_option backward.isDefEq.respectTransparency false` at file level repairs 13 of the 24 with no proof edit.
- 613 deprecation warnings (`if_pos` 121, `if_neg` 110, `if_true` 194, `if_false` 184, `dif_pos` 4 →
  `ite_eq_left`, `ite_eq_right`, `ite_true`, `ite_false`); still compile. 1202 warnings in total
  (the rest mostly unused-simp-arg / unused-variable linters).

The first build stops at 4 roots (`ParInv`, `ParRunFlat`, `ParRunWFStep`, `ParRunCInv`) which block most of
the folder; the other 20 only show up after those are repaired, so a plain `lake build` under-reports.

## Effort estimate

- Minimal port (file-level backward option on 22 files + the 13 one-line edits in 11 files listed above):
  **about 1 prover-hour**; it was done once in scratch in roughly 15 minutes, iteratively.
- Clean port without the backward option (rewrite the 13+ option-only modules, notably the `ghost_auto` macro
  in `ParRunWFStep` and the `split`/`rw` sites): **3 to 6 prover-hours**, uncertain; the failures are shallow but
  each site has to be looked at.
- Deprecated `if_*` names (613 sites): mechanical rename, **under 1 hour**, optional.
- Unknown: the 2 Sail-dependent modules, and whether the option stays available in later releases.
